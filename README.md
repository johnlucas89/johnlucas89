## Featured Project

**[Predictive Maintenance: Machine Failure Detection](https://github.com/johnlucas89/predictive-maintenance-failure-detection)**
Compared Random Forest, PyTorch, and TensorFlow/Keras models on the AI4I 2020 dataset to predict machine failure — with a focus on failure recall over raw accuracy, since a missed failure is far more costly than a false alarm in a real plant. Best model recovers 88% of real failures.
